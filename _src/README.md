# Исходники и инструменты Гаражника (для следующих сессий Claude)

Папка `_src` не публикуется на сайте (GitHub Pages/Jekyll пропускает папки с `_`).

## Как устроен сайт
- `index.html` — всё приложение в одном файле, роутинг по хешу (#to, #faults, #symptoms, #lamps, #codes, #fuses, #garage, #tools, #parts, #schedule, #numbers, #about, #<id работы>).
- Две темы (data-theme, localStorage `garazh-theme`), гараж хранится только в браузере (localStorage), персональные данные не собираем.
- `stati/` — 47 страниц: 35 статей, 6 страниц семейств `obsluzhivanie-*` (все цифры) и 6 страниц современных моделей `lada-*` (поколения, история, новости, проблемы); генерируются скриптом, `sitemap.xml` тоже.
- `sw.js` — при изменениях index.html повышай CACHE (сейчас garazhnik-v8).
- НЕ удалять: CNAME, yandex_5841f4e2fd5a3a59.html, googleb7db3b655183b61b.html.

## Сборка статей
```
cd _src/art && python3 build.py ../..     # пересобирает stati/*.html, stati/style.css, sitemap.xml
```
- `articles.py` — хелперы + статьи 1–15, подключает `articles2.py`, `articles3.py`, `articles4.py` (предохранители, берёт данные из `../feat/fuses.py`), `articles5.py` (страницы моделей: цифры по моторам из data.json, регламент, ссылки `../?fam=<семейство>#<работа>`). В конце assert на число статей — меняй при добавлении.
- build.py сам вписывает список статей в index.html между `const ARTS = ` и `/*ARTS*/` — из него работают поиск, блок «Почитать подробнее» в инструкциях и ссылка на страницу модели. После правки статей всегда пересобирай.
- `data.json` — цифры, схемы и CSS, выгруженные из приложения. Цифры, регламент и каталог моделей — `export4.js` (сервер на 8765), схемы и CSS — `export3.js`. После правки цифр в index.html: export4.js → build.py.
- `articles6.py` — страницы современных моделей (Гранта, Веста, Искра, Нива Легенд, Нива Тревел, Ларгус): тексты истории/новостей/проблем со ссылками на источники. Новости дописывай сюда с датой и источником.
- Даты: поле `date` у статьи, NOW/TODAY в build.py.

## Приложение: что где
- Поиск: `parseQuery`/`match` — основы слов (`stem`), синонимы (`SYN`), модели (`MODEL_WORDS`: «2107», «гранта»… → семейство и предохранители), статьи из `ARTS`. Если точного нет — мягкий режим «Похожее».
- Симптомы: `SYMPTOMS` (27 шт.), id по порядку в `SYM_IDS`, разделы — `SYM_GROUPS`, поле `k` — доп. слова для поиска. Новый симптом: добавь в все три.
- Первый визит: блок «ТО Лады своими руками» с выбором модели (пока нет `garazh-fam`/`garazh-welcome`). `?fam=<ключ>` в адресе выбирает модель.
- `fitSvgs` после отрисовки расширяет viewBox схем, чтобы подписи не обрезались (в статьях то же — скрипт в build.py).

## Каталог машин
- `MODELS` в index.html: модель → поколение (`fam` — семейство с общими цифрами, `engs` — моторы из `ENG[fam]`, `v` — свои цифры поколения, `note`). Выбор хранится в `garazh-gen`; `?gen=<id>` в адресе выбирает поколение.
- Цифры: семейство (FAM/FAM_BASE/FAM_EXTRA/FAM_SUSP) ← мотор (ENG.v) ← поколение (v). Непроверенное двумя источниками — `UTOCH` («уточняется — сверь с сервисной книжкой»), выводится серым.
- `belt:true` у мотора в «цепном» семействе (Нива 1,8 11184) — `isChain()` ложно: ремень ГРМ, без регулировки клапанов по классике. `RWD` — заднеприводные (порядок прокачки, масло каждые 10 000).
- Новое семейство `travel` (Шевроле Нива / Нива Тревел), почти всё «уточняется».
- Фаза 2 (не сделано): Приора/Калина/классика/Самара/десятка подробно по моторам (11189, H4M, 21114 и др.), страницы этих моделей; свои схемы предохранителей для Весты NG, Искры, Ларгуса FL, Иксрея, Тревела.
