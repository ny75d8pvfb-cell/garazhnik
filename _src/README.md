# Исходники и инструменты Гаражника (для следующих сессий Claude)

Папка `_src` не публикуется на сайте (GitHub Pages/Jekyll пропускает папки с `_`).

## Как устроен сайт
- `index.html` — всё приложение в одном файле, роутинг по хешу (#to, #faults, #symptoms, #lamps, #codes, #fuses, #garage, #tools, #parts, #schedule, #numbers, #about, #<id работы>).
- Две темы (data-theme, localStorage `garazh-theme`), гараж хранится только в браузере (localStorage), персональные данные не собираем.
- `stati/` — 35 статей, генерируются скриптом, `sitemap.xml` тоже.
- `sw.js` — при изменениях index.html повышай CACHE (сейчас garazhnik-v5).
- НЕ удалять: CNAME, yandex_5841f4e2fd5a3a59.html, googleb7db3b655183b61b.html.

## Сборка статей
```
cd _src/art && python3 build.py ../..     # пересобирает stati/*.html, stati/style.css, sitemap.xml
```
- `articles.py` — хелперы + статьи 1–15, подключает `articles2.py`, `articles3.py`, `articles4.py` (предохранители, берёт данные из `../feat/fuses.py`). В конце assert на число статей — меняй при добавлении.
- `data.json` — цифры, схемы и CSS, выгруженные из приложения (`export3.js` через Playwright).
- Даты: поле `date` у статьи, NOW/TODAY в build.py.

## Предохранители
- Данные: `feat/fuses.py` (10 моделей), рисунок `feat/fusefig.py`, вставка в index.html — `feat/fuses_patch.py` (уже применён; повторно применять только к версии без раздела).

## Проверка
Локально: `python3 -m http.server 8765` в корне репо, скриншоты Playwright (`require('playwright')`, chromium уже установлен).

## Пробелы в данных (сверить)
Момент гайки ступицы Ларгуса; моменты кулака Самары/Десятки; суппорт Гранты; ключи сливных пробок; интервал ГРМ Гранты (в приложении 60 тыс., источники 75 тыс.); номера 21080-1012005 и MANN W 914/2; нижний ряд F17–F20 у 2110.

Страницы моделей; видео без своей машины (анимации схем, запись экрана, карточки); статьи по Вордстату 2–3 в неделю (карбюратор 2107 и др.); напоминания о ТО; «Помогла ли инструкция?»; монетизация позже (партнёрки, РСЯ от ~300–500 визитов/день, реклама в TG).
